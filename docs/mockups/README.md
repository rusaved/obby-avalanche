# Макеты мобильного интерфейса (веха MU «Мобильный интерфейс»), версия 2

Игра только альбомная. Кадр макета 812×330 CSS px — видимая зона альбомного экрана телефона под панелями браузера; на картинке 1 CSS px = 2 px. Экран поворота — 375×650. Правила, токены и словарь — `docs/07-mobile-ui.md`. Сцена в макетах условная: задаёт только состав, положение и размеры элементов интерфейса, не арт. Числа на макетах условные; сборка берёт свои.
