## Правки по важности

1. **(2) Точка появления на warn — обязательная.** Трещина красится `front[1]` (почти цвет тумана), гряда — константа `CLUMP_WARN_SCALE = 3` в коде.
   - `content/avalanche/theme.json` → `threat.crack` (нового поля нет — завести, сейчас берётся `front[1]`): было `#BFE6FF` → стало цвет тени горы, по умолчанию `#7F9CC0`, для гор — их `threat.worlds.<id>.shadow`. Тёмная холодная черта поперёк склона видна с 160 ед и не страшная.
   - `content/avalanche/tuning.json` → `avalanche.warnRidgeScale` (вынести из `CLUMP_WARN_SCALE`): было 3 → стало 5; на `low` (половина комьев) — не меньше 5, иначе гряда редеет.
   - Проверка: на `avalanche-m04-1-warn-low.png` гряда шириной не меньше трети дорожки на горизонте и выше великана по контрасту.
2. **(4) Комья как снег — обязательная.** Серые грани дают плоское затенение и слабое свечение (`CLUMP_GLOW = 0,45` в коде).
   - `content/avalanche/tuning.json` → `avalanche.clumpGlow` (вынести из `CLUMP_GLOW`): было 0,45 → стало 0,75 — тени граней станут голубоватыми, не серыми.
   - Форма: гранёный многогранник → скруглённый (больше сегментов или сглаженные нормали) — правка кода `avalanche.ts`, без нового draw call; размер у камеры ограничить (`CLUMP_SIZE` 1,9 → 1,4 для комьев ближе 10 ед).
   - Тень и пыль: `content/avalanche/theme.json` → `threat.shadow` был `#7F9CC0` → стал `#6D8DB8` (чуть темнее, чтобы полоса перед фронтом читалась на снегу); пыль на run сейчас не видна — размер точек 1,6 вынести в `tuning.json` → `avalanche.dustSize` и поднять до 2,4.
3. **(5) Кадры контента — обязательная.** Доказательство не показывает то, что должно.
   - `e2e`-кадры `figures-skins-*`, `figures-wings-*` снимать после вылупления (без шара и тоста) и камерой сбоку на 3/4, чтобы крылья были видны; без этого скины и крылья на фигуре не проверены.
   - «Гардероб»: значок скина/крыльев 10–16 px → 36–40 px (поле размера значка в `theme.json` → `ui` нет — завести, например `ui.wardrobe.iconPx`); «Пингвин», «Снежок», «Золотой» сейчас не отличить друг от друга.
   - Ауры в «Магазине»: у всех один значок «+» → свой значок на ауру (`content/avalanche/auras.json` → поле значка у каждой, нового поля нет — завести).
4. **(3) m01 и m04 одинаковы.** `content/avalanche/theme.json` → `threat.worlds.falls.front[1]`: было `#BDE4F7` → стало `#9FD8EE` (бирюзовее, «водопадная» вода), `shadow` `#6A9CBF` → `#4F93B5`. Не обязательная, но без неё «своя лавина у каждой горы» на горе 4 не заметна.
5. **(6) Белая стрелка к пещере.** `content/avalanche/tuning.json` → `avalanche.arrowScale`: было 2 → стало 1,4 и цвет стрелки — голубой акцент пещеры вместо белого (поле цвета в `theme.json` → `threat` нет — завести `threat.arrow`); на всех 7 кадрах warn/run стрелка заходит под полосу «Уровень 1».
