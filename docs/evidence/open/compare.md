# Простор против прототипа: договор измерения (`docs/06` 8.2)

До выхода — модель экономики (`npm run sim:balance`, отчёты `docs/evidence/balance-open.txt` и `balance-fast.txt`) и смоук (физический бот в e2e: `open-first-minute.spec.ts` для `open`, `fast-mountain.spec.ts` для `fast`; события — `docs/evidence/open/ftue-events.txt`). После выхода — две группы флага `pace` (строка 6 таблицы 8.1) 7 дней: столбец заполняет продюсер по Консоли и Метрике (сегмент — `gameReady` с `pace`).

Бот модели и бот e2e — не игроки: они не уходят из игры, поэтому главные показатели до выхода видны только через заменители (когда в первую минуту случается награда, сколько поимок). «Интересно ли» решает продюсер.

Как читать: модель и смоук говорят, что простор не медленнее прототипа в первую минуту по наградам (кроссовки, лавина, яйцо в те же 20–25 с), но гора 1 длиннее (2 мин против 1,2) и рубежей меньше, чем ворот: между рубежами 1 и 2 у бота 49 с без нового «замка». Это главный риск для доли сессий дольше 60 с — проверяет только живая группа.
