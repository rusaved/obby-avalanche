## Правки для оценок 3

1. **Телепорт без пройденных этапов** (`src/app/camp-view.ts` ~175): если пройденных нет — вместо списка замков одна строка «Пройди этап 2 — сюда можно вернуться»; у открытых строк цена с монетой.
2. **Питомцы пустые**: под `pets.empty` (`src/ui/pets-panel.ts` 88) синяя кнопка «К яйцам» в магазин, вкладка «Яйца»; шапку «Питомцы 0/27» → «Собрано 0/27».
3. **Слова** (`content/avalanche/i18n/ru.json`, и en): `reward.boost` 326 → «Скорость ×2», срок только в подстроке; `daily.r3` 294 → «Скорость ×2 на 10 мин»; `shop.need` 240 → «Нужно ещё {n}» с кубком; `rebirth.toTier` 268 → «На ступень {n}»; `quests.q_walls` 309 → «Пройди рубежи: {n}»; `daily.r1` 292 → «Монеты {n}».
4. **Перерождение при 130 %**: убрать правило `:has(.rb-btns)::after { display: none }` или дать шеврон самой полосе `.rb-btns` (справа над кнопками), чтобы прокрутка была видна.
5. **Задания**: `quests.bonus` перенести в подзаголовок окна (видно без прокрутки); при желании — награда справа в строке задания.
6. **Гардероб**: фигурки скинов в карточке крупнее (≈ 32 px по высоте), цена с кубком — под именем.

## Что не нравится, но не 3

- Кубки приходят из «Подарков», календаря и заданий, словарь `07` — «только вершины» (ждёт продюсера, повтор).
- Реклама в «Подарках» в нижней трети окна — макет `w1` против правила 13 (ждёт продюсера, повтор).
- Подзаголовок «Паузы» — название игры; полезнее «игра стоит, лавина ждёт».
- На кадрах 130 % в «Подарках» на 915 кнопка «ВКонтакте» целиком под затуханием — вход в группу виден наполовину.
