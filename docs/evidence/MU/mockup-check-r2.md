# Круг правок MU: повторная сверка сборки с макетами

Как сверял: макет `docs/mockups/*.png`, уменьшенный до 812×330, ставил рядом с верхними 330 px кадра сборки 812×375 из `docs/evidence/MU/812x375/` и замерял по пикселям: панели окон — по цвету `#152230`, прыжок и полосы — по цвету токенов. Кадры `915x412/` смотрел как второй размер. Допуски: положение ±41 px по горизонтали и ±16 px по вертикали, размеры кнопок ±2 px. Сцену (рельеф, числа, таймеры) не сравнивал. Решения `docs/допущения.md` 95–97 и Q-MU-11…Q-MU-14 расхождениями не считал.

Проверено:
- экраны l1, l2, l3 (до финиша и финиш), l4, l5 (лагерь с кнопкой рекламы и база с порталами);
- окна w1–w6 и экран поворота p1;
- вторая волна: Магазин и вкладка «Шаги», Питомцы, Гардероб, Перерождение, Рекорды, Задания, Календарь, Промокод;
- три окна при 130 %;
- те же кадры на 915×412. Раскладка там та же: окна по центру видимой зоны (34–334 при высоте 367), панели не выше 300, нижние 45 px свободны.

Не проверено:
- **l2.** В кадре в слоте стоит тост «УРОВЕНЬ ВЫШЕ!», плашки «Ещё N уровня до рубежа» нет: кадр снят в момент повышения уровня. Плашку сверил по кадру `l3-stage-finish-before`.

- **Кадры при 130 % и `p1-rotate` недостоверны** (раздел «130 %» ниже).
- Поведение (прокрутка, тап-зоны, частота «+N») по кадрам не проверить, это проверяют e2e.

- «+150» с монетой стоит на 14 px ниже полосы этапов, у монеты есть зазор;

- кнопка «Переродиться» прибита к низу окна;

## Чинить до сдачи (оценка 2)
1. **l3 финиш.** Табличка «Награда этапа · ⊛ N / можно бежать мимо» гаснет в момент финиша, а в макете она стоит рядом с «+130». Причина: `src/app/stage-view.ts` пропускает площадку при `sim.padTaken[k]`. Вариантов правки два: пропускать взятую площадку, только когда герой с неё сошёл, или записать решение «гаснет при взятии, её место занимает „+N“» в `docs/допущения.md` и отметить в `l3`.
2. **w5 «Гора пройдена».** Колонка значений ломается: «+500» начинается с x 345, остальные значения с x 418, в макете все с 362. Правка — `src/styles.css:679`: `#ui.mu .sm-row { grid-template-columns: 180px 1fr auto; }`. Колонка названий станет одной ширины во всех строках, значения встанут на x 362.
3. **130 %.** Кадры недостоверны, в «Подарках» значки лежат на тексте.
