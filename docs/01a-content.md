# 01a. Контент и баланс: таблицы

Приложение к `docs/01-gdd.md`. Здесь — числа и списки, которые ложатся в `content/avalanche/*.json`, и все тексты для игрока ru/en. Правила, по которым эти числа работают, — в `01-gdd.md` (номера разделов указаны).

- Все числа — стартовые. Меняешь — меняешь данные, пишешь в `progress.md`, прогоняешь `npm run sim:balance`.
- Числа с суффиксами записаны для краткости: 1.2K = 1 200, 25B = 25 000 000 000. В JSON — полные числа.
- Стены, подарки и цены — для ступени 0. На ступени n умножаются на `wallScale[n]`, стены 37–60 при n ≥ 1 — ещё на `ease(p)` (раздел 9).
- id — латиницей, как в данных. Тексты — ключами `i18n` (раздел 11).

## 9. Перерождение: ступени

## 14. Пакет `_sample` (проверка «игра 2 — замена данных»)

Мини-пакет `content/_sample/` для валидатора (M0-07), `e2e:sample` и `sample.spec.ts` (M5-09): доказывает, что игра 2 собирается заменой данных (`02`, 5.1; `01`, 13). Игрокам не показывается, в релиз не входит (сборка по умолчанию — `avalanche`). Числа и тексты ниже проверочные, это не решение по игре 2. Чего нет в этом разделе — копия файла из `content/avalanche/` без изменений: `tuning.json`, `pets.json`, `eggs.json`, `skins.json`, `accessories.json`, `trails.json`, `auras.json`, `bots.json`, `sfx.json`, `studio-presets.json`.

**Код ради `_sample`** меняется только в двух местах: модуль эффекта `src/sim/effects/jumpPower.ts` (до 100 строк) и, если понадобится, новый тип сегмента в каталоге `src/level/catalog.ts`. Любая другая правка — дефект архитектуры: различие выносится в данные, запись в `docs/допущения.md`.

### 14.1 `game.json` (отличия от `avalanche`)

```json
{
  "id": "_sample",
  "stat": { "key": "jump", "effect": "jumpPower" },
  "threat": { "kind": "wave", "visual": "lava" }
}
```
- Остальные поля (`leaderboard`, `ads`, `metrikaCounterId`, `mobileOrientation`) — как у `avalanche`.
- `threat.visual: "lava"` не выбирает код: модуль рендера волны один (`02`, 8), вид лавы целиком задают параметры `theme.json` (14.4).
- До M5-09 эффекта `jumpPower` нет (контроллер появляется на M1): на M0–M4 в `_sample` стоит `"effect": "moveSpeed"`, переключение на `jumpPower` — фича M5-09. Остальные числа пакета — с M0 такие, как ниже.

### 14.2 `balance.json` (отличия от `avalanche`)

| Ключ | Значение | Зачем |
|---|---|---|
| `jumpCurve` | `{ "base": 50, "k": 0.25, "max": 100 }` | скорость отрыва при прыжке от стата, ед/с: `min(max, base × (1 + k × log10(1 + Прыжок)))` — та же форма, что у `speedCurve` (`01`, 8.1). Высота = v² / (2 × 196,2) |
