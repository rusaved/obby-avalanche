# Звуки, выбранные продюсером 16.10

Файлы mp3, сгенерированы для игры. Встроить по брифу вехи «Лавина 10 · Доводка» и перенести в постоянное место ассетов; эту папку после встройки удалить.

## Шаги (окно «Звук шагов»)

| Набор | Папка | Как открывается | Заметка |
|---|---|---|---|
| Лёгкий снег | `steps/light-snow` | сразу, по умолчанию | фаворит продюсера, особенно `1.mp3` — чаще остальных |
| Шёпот снега | `steps/whisper-snow` | сразу | два варианта |
| Бархатный снег | `steps/velvet-snow` | сразу | |
| Волшебный снег | `steps/magic-snow` | в магазине за кубки | |
| Тихий наст | `steps/quiet-crust` | в магазине за кубки | |
| Лёд (для всех наборов) | `steps/ice` | — | на ледяных участках вместо снега |

Внутри набора варианты чередуются случайно, без повтора подряд.
